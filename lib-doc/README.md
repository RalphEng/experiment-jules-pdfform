# Bibliotheks-Dokumentation

Dieses Verzeichnis enthält Dokumentation für die verwendeten externen Bibliotheken im Projekt.

## Struktur

```
lib-doc/
└── pdfbox/
    ├── pdfbox-forms-documentation.md  # Vollständige Dokumentation zu Formularen
    └── code-examples.md               # Praktische Code-Beispiele
```

## Apache PDFBox

### pdfbox-forms-documentation.md
Umfassende Dokumentation zur Arbeit mit PDF-Formularen in Apache PDFBox 3.0.6:
- Formularfelder und AcroForm
- Dokumente laden
- Formularfelder ausfüllen
- Formular-Flattening
- Signaturfelder
- Button-Felder (Checkboxen, Radiobuttons)
- Best Practices

### code-examples.md
Praktische, lauffähige Code-Beispiele für häufige Aufgaben:
- Formularfelder auflisten
- Textfelder ausfüllen
- Checkboxen und Radiobuttons handhaben
- Dropdown-Listen (ComboBox) bedienen
- Formulare aus Properties-Dateien befüllen
- Formulare flattenen
- Verschachtelte Felder auslesen
- Feld-Validierung
- Komplettes CLI-Tool Beispiel

## Verwendung

Diese Dokumentation dient als Referenz während der Entwicklung und kann jederzeit konsultiert werden, um:
- Die korrekten API-Aufrufe zu finden
- Best Practices zu verstehen
- Häufige Probleme zu vermeiden
- Schnell lauffähigen Code zu haben
